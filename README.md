# National Hospitalised Injury Trends in Australia — Data Visualisation

An interactive data visualisation project exploring hospitalised road injury trends in Australia, focusing on road users aged **40–64** and comparing male and female hospitalisation counts.

## Project Overview

The website presents road injury data through interactive charts, helping users compare trends across road user groups and years. It includes a **Car Drivers Hospital Injuries line graph**, a **Motorcyclist bar chart**, a **Pedal Cyclist Hospitalisations bar chart**, and a page summarising key findings and data notes.

## Visualisations

- **Car Drivers Hospital Injuries — line graph:** compares male and female car driver hospitalisations over time.
- **Pedal Cyclist Hospitalisations — bar chart:** compares male and female pedal cyclist hospitalisations by year.
- **Motorcyclist — bar chart:** provides another road user comparison.

The charts use interactive tooltips to make yearly values and differences easier to explore.

## Key Findings

- Males recorded higher hospitalised injury counts than females across car drivers, motorcyclists, and pedal cyclists for most of the period examined.
- Car driver hospitalisations were relatively stable over time, with male counts consistently higher than female counts.
- Pedal cyclist hospitalisations were generally lower than car driver hospitalisations, while still showing a difference between males and females.
- Injury patterns varied by road user group, sex, and year.

**Data note:** The project report identifies changes in hospital admission criteria in Victoria (from 2012) and New South Wales (from 2017) that can affect comparisons between years.
